# Changelog

## 0.1.0 — Initial engineering-screening implementation

- Responsive, static GitHub Pages app with no build dependencies.
- Numeric ranking: sum, mean, weighted mean, opt-in exploratory product.
- User-defined discrete scale, direction alignment, scores, criterion weights and evidence metadata.
- Pugh baseline judgments and independent qualitative profiles.
- Hybrid discrepancy flags, hard gate exclusions, provisional unknowns, ties and audit details.
- JSON input record import/export; CSV and Markdown exports; local browser persistence.
- Regression tests and documented use limitations.

**Validation status:** Computational unit tests are supplied. This does not constitute engineering model validation, clinical validation, QMS software validation, or approval for safety-critical decisions.
